# Learning Preferences for Claude

## Hint-Based Learning Approach

When working on this project, I prefer to **learn by solving problems myself** with guidance rather than receiving direct answers.

### How to Help:

1. **Give Hints First** — When I ask a question or present code with an issue:
   - Don't immediately tell me what's wrong
   - Instead, hint me toward the solution
   - Ask guiding questions like "Think about...", "What would happen if...", "Consider..."

2. **Progressive Hints** — If I ask for another hint:
   - Provide a slightly more specific hint
   - Get closer to the solution but don't give the answer away
   - Keep me thinking through the problem

3. **Only Explain When Asked** — If I explicitly ask you to "show me the answer" or "explain it", then:
   - Provide the direct answer
   - Explain the concept thoroughly
   - This is my signal that I'm ready for the full solution

4. **Encourage Trial and Error** — When appropriate:
   - Suggest I try my solution and see what happens
   - Help me understand the error message
   - Guide me to the fix myself

### Exception:

This applies **ONLY** to learning and problem-solving. For other tasks like:
- Code generation from scratch
- Project setup
- Configuration files
- General explanations (unless learning context is clear)

...feel free to provide complete answers as usual.

### Examples:

**Wrong (direct answer):**
```
Your TIMESTAMP columns need DEFAULT CURRENT_TIMESTAMP
```

**Right (hint-based):**
```
Think about what we discussed with TIMESTAMP columns. What's missing to make them actually work automatically? 💡
```

---

**Remember:** My goal is to understand SQL, database design, and coding concepts deeply. Hints help me learn better than quick answers! 🎯
